# 🦖 T-Rex Runner (Chrome Dino Clone)

A lightweight, zero-dependency Chrome Dino Game replica built using HTML5 Canvas, Vanilla JavaScript, and CSS. Native audio effects are dynamically generated using the Web Audio API.

## 🚀 Features

- **Zero Asset Dependencies**: Dinosaur, cacti, pterodactyls, and audio are generated dynamically in code.
- **Physics Engine**: Smooth gravity, variable jumping, fast-falling, and crouch state mechanics.
- **Dynamic Speed Scaling**: Game speed ramps up continuously as your score increases.
- **Day/Night Cycle**: Theme colors smoothly invert every 700 points.
- **Synthesized Audio**: Retro jump, score milestone chime, and game-over crash sounds built with Web Audio API.
- **Persistence**: High score saved locally using `localStorage`.
- **Responsive & Mobile Ready**: Playable via Keyboard (Space, Up, Down arrows) and Touch events.

## 🎮 Controls

| Action | Keyboard | Touch (Mobile) |
| :--- | :--- | :--- |
| **Jump / Start / Restart** | `Space` or `Up Arrow` | `Tap Screen` |
| **Duck / Fast Fall** | `Down Arrow` | — |

## 🛠️ Deploying to GitHub Pages

1. Create a new repository on GitHub.
2. Push `index.html`, `style.css`, `script.js`, and `README.md` to your `main` or `master` branch.
3. Go to **Settings** > **Pages** in your repository.
4. Set the **Source** to `Deploy from a branch` and choose `main` (or `master`) / `/ (root)`.
5. Click **Save**. GitHub Pages will give you a live link to play your game!
